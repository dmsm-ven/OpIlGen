# OpIlGen

WPF-приложение (.NET 10) для превращения изображений в оптические иллюзии и художественные эффекты.
MVVM (CommunityToolkit.Mvvm), DI (Microsoft.Extensions.DependencyInjection), анализ звука на NAudio.
Результаты сохраняются в `Output` рядом с exe, настройки - в `%APPDATA%\OpIlGen\settings.json`.

## Главное окно
- **Файл:** кнопка «Выбрать файл...» или одна из последних 8 картинок на панели плиток (список запоминается).
- **Преобразователи:** «Оригинальное фото» вынесено отдельной кнопкой над списком. В списке избранные (звёздочка) стоят сверху, остальные идут по алфавиту выбранного языка.
- **Параметры:** у каждого преобразователя (кроме оригинала) свои ползунки справа под списком, значения запоминаются при переключении.
- **Результат** считается в фоне и сохраняется в файл с небольшой задержкой. Двойной клик по изображению открывает его на весь экран.

## Преобразователи (26)
- **Базовые:** Оригинальное фото, Чёрно-белое (2 цвета), Эффект Линкольна (пикселизация)
- **Послеобразы:** Негативное послесвечение, Позитивный послеобраз (виден с закрытыми глазами)
- **Растр и дизеринг:** Флойд-Стейнберг, Байер (упорядоченный), Полутоновый растр (halftone)
- **Иллюзии восприятия:** Сетка Германа, Кафе-стена, Автокинетическая иллюзия, Периферический дрейф
- **Рисунок и живопись:** Рисунок карандашем, Масляная живопись, Мягкий карандашный набросок
- **Размытия:** Мягкий фокус (боке), Размытие в движении, Размытие поверхности
- **Искажения и генеративные:** Slit-scan, Карта смещения, Сортировка пикселей, Калейдоскоп, Линейный оп-арт, Вороной / stippling, Поле направлений, Карта высот

Новый преобразователь: реализовать `IImageTransformer`, зарегистрировать в `App.ConfigureTransformers`, добавить тексты в `Localization/*.json`.
Параметры: переопределить `AvailableCustomVariables` и читать значение через `customVariables.GetValue(variable)`.

## Генератор GIF
Открывается для текущего файла и преобразователя. Кадры - строки таблицы (столбцы - параметры), между ними можно включить плавный переход или fade-in / fade-out.
«Склеить» сохраняет зацикленный GIF в `Output/gif/<имя файла>.gif`. Кодировщик (`Services/GifEncoder.cs`) написан без зависимостей, длинная сторона ограничена 1024 px.

## Окно музыки
Параметры преобразователя меняются в такт музыке на живом превью. Каждому параметру назначается характеристика звука (бас, громкость, средние, высокие, бит, яркость)
или фиксированное значение. Привязки запоминаются для каждого преобразователя, как и последний трек, FPS и громкость. Есть перемотка, до 8 недавних треков
и полноэкранный режим по двойному клику.

## Настройки, темы и языки
Окно настроек (шестерёнка справа на верхней панели): светлая / тёмная тема, язык, путь к файлу настроек с кнопкой открытия.
Кисти тем лежат в `Themes/*.xaml`, тексты - в `Localization/<код>.json` (сейчас `ru` - основной и `en`), файлы встраиваются в сборку.
Чтобы добавить язык, создайте, например, `de.json` со всеми ключами из `ru.json` и ключом `language.name`: язык появится в настройках сам, недостающие ключи берутся из русского.
В XAML: `Text="{loc:Loc ключ}"`, в коде: `ILocalizationService.Get("ключ")` или `Format("ключ", аргументы)`.

## Открытие изображения из браузера
Кнопка «Открыть в OpIlGen» на странице с прямой ссылкой на картинку передаёт адрес в программу: она скачивает файл (в `%LOCALAPPDATA%\OpIlGen\Downloads`) и открывает его как через «Выбрать файл...».

1. Отредактируйте путь к `OpIlGen.exe` в `Tools/register-opilgen-protocol.reg` и импортируйте файл (запись в `HKEY_CURRENT_USER`, права администратора не нужны).
2. В Tampermonkey создайте скрипт из `Tools/OpIlGen-open-button.user.js`. Кнопка появляется на страницах с одним изображением (jpeg, png, gif, bmp, tiff).
3. При первом клике Chrome спросит разрешение открыть OpIlGen (можно отметить «Always allow»).

Приложение работает в одном экземпляре: повторный запуск передаёт ссылку открытому окну и поднимает его.
Формат запуска: `OpIlGen.exe "opilgen://open?url=<адрес, закодированный encodeURIComponent>"`.
