# OpIlGen

WPF-приложение (.NET 10) для превращения изображений в оптические иллюзии.

- MVVM: CommunityToolkit.Mvvm
- DI: Microsoft.Extensions.DependencyInjection (главное окно создаётся через контейнер)
- Результат сохраняется в папку `Output` рядом с exe

## Преобразователи
- Оригинальное фото (без изменений)
- Чёрно-белое (строго 2 цвета)
- Негативное послесвечение
- Позитивный послеобраз (виден с закрытыми глазами)
- Дизеринг Флойда-Стейнберга
- Дизеринг Байера 8x8
- Полутоновый растр (halftone)
- Эффект Линкольна (пикселизация)
- Сетка Германа
- Кафе-стена
- Автокинетическая иллюзия (приближение, параллельные линии с острыми окончаниями)

Новый преобразователь: реализовать `IImageTransformer` и зарегистрировать в `App.ConfigureServices`.

## Темы
Светлая и тёмная тема переключаются иконками справа на верхней панели. Кисти тем лежат в `Themes/*.xaml`. Выбранная тема сохраняется в `%APPDATA%\OpIlGen\settings.json` и применяется при следующем запуске.

## Настраиваемые параметры
У преобразователя могут быть свои параметры (`IImageTransformer.AvailableCustomVariables`): для каждого в правой панели под списком
выводится ползунок. Сейчас параметр есть у «Эффекта Линкольна» (количество блоков). Чтобы добавить параметр в другой
преобразователь, переопределите `AvailableCustomVariables` и читайте значение через `customVariables.GetValue(variable)`.

## Генератор GIF
Кнопка справа от «Открыть папку» открывает окно генератора для текущего файла и преобразователя. Кадры задаются таблицей: строка - кадр, столбцы - номер и параметры
преобразователя; кнопка «+» под таблицей добавляет строку. Между кадрами можно включить плавный переход (промежуточные кадры с
интерполяцией параметров) или fade-in / fade-out (появление из чёрного и затухание). «Склеить» создаёт изображение для каждого кадра и собирает
из них зацикленный GIF в `Output/gif/<имя файла>.gif`. Кодировщик GIF (`Services/GifEncoder.cs`) написан без зависимостей от WPF:
локальные палитры, медианное сечение, LZW. Длинная сторона изображения ограничена 1024 px.

## Языки
Язык и тема выбираются в окне настроек (кнопка с шестерёнкой справа на верхней панели) и сохраняются между запусками.
Все тексты лежат в `Localization/<код языка>.json` (сейчас `ru.json` - основной, и `en.json`), файлы встраиваются в сборку.
Чтобы добавить язык, достаточно создать файл, например `de.json`, со всеми ключами из `ru.json` и ключом `language.name`
(название языка на нём самом): язык появится в настройках сам. Отсутствующие ключи берутся из русского файла.
В XAML текст подключается так: `Text="{loc:Loc ключ}"`, в коде - `ILocalizationService.Get("ключ")` или `Format("ключ", аргументы)`.
